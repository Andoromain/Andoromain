## À propos

Développeur full-stack basé à **Antananarivo, Madagascar**.
Je conçois des applications métier de bout en bout : de la base de données et de l'API jusqu'à l'interface et au serveur qui les fait tourner.

- 🧱 **Backend** : applications Laravel, API REST, files d'attente et workers (Horizon, BullMQ)
- 🎨 **Frontend** : interfaces Vue.js et React avec Vuetify, PrimeReact et Mantine UI
- ⚙️ **Infrastructure** : Nginx, Supervisor, Docker, Ansible, supervision avec Prometheus et Grafana
- 🤖 **Outils IA** : modèles locaux avec Ollama et extensions pour assistants de code IA
